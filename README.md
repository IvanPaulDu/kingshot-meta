# Snake - Juego Sencillo

Un juego clásico de Snake hecho con HTML, CSS y JavaScript puro (sin dependencias).

## Cómo jugar

Abre `index.html` en cualquier navegador, o sirve la carpeta con un servidor local:

```bash
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`.

## Controles

- Flechas o `WASD` para mover la serpiente.
- `Espacio` para pausar, reanudar o reiniciar tras perder.

El récord se guarda en el navegador (`localStorage`).
